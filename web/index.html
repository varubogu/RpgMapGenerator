RpgMapGenerator

RPGツクールMV/MZ用のダンジョンを自動生成します。処理はすべてブラウザ内で完結し、データは送信されません。

ツクールへの取り込み方
  1. ツクールのエディタで新しいマップを作り、そのマップIDを左の「マップID」に入力します。
  2. プロジェクトを保存してエディタを閉じます(開いたままだと上書きされます)。
  3. ダウンロードしたファイルを、プロジェクトの data フォルダに上書きコピーします。
  4. エディタを開き直すと、生成したマップが入っています。

既定のタイルは標準の「ダンジョン」タイルセット(ID 4)を想定しています。壁の通行設定はタイルセット側で決まるので、 壁が通行不可になっていることを確認してください。場所移動先は入口・出口のイベントで設定します。
